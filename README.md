# THREADX Premium Clothing Store Website

A responsive, premium black-and-white fashion storefront built with HTML, CSS and vanilla JavaScript. Designed for free GitHub Pages hosting.

## Included
- Premium editorial-style landing page
- Responsive desktop and mobile layout
- Clothing collection with category filters
- WhatsApp order links for each product
- Size and quantity prompts before ordering
- Brand story, brand values and contact sections
- Floating WhatsApp contact shortcut
- Mobile navigation

## IMPORTANT: Set up your business details first
Open `script.js` and replace:
- `8801XXXXXXXXX` with your real WhatsApp number in international format, without `+`, spaces or dashes.
- `THREADX_INSTAGRAM_URL` with your Instagram profile URL.
- `THREADX_FACEBOOK_URL` with your Facebook page URL.

Then open `index.html` and update the sample products, prices and image URLs with your actual catalogue. Current product details and photographs are examples only. Use images you own or have permission to publish.

## Publish with GitHub Pages for free
1. Extract this ZIP on your computer.
2. Open your GitHub repository `threadx-website`.
3. Click **Add file → Upload files**.
4. Upload `index.html`, `style.css`, `script.js`, and `README.md` from this folder (not the ZIP itself).
5. Click **Commit changes**.
6. Go to **Settings → Pages**.
7. Under **Build and deployment**, choose **Deploy from a branch**.
8. Choose branch **main** and folder **/(root)**, then click **Save**.
9. Your site URL will be `https://YOUR-GITHUB-USERNAME.github.io/threadx-website/`.

## Hosting limitations
GitHub Pages hosts static files. WhatsApp is used for order enquiries; this starter website does not have a database, inventory management, admin dashboard or built-in card checkout. External image/font services require an internet connection.
